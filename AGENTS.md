# Available Custom Agents

The following agents in `.agents/agents/` are registered for AGY:

- **@accessibility-auditor**: Audit WCAG compliance, keyboard navigation, ARIA, screen reader usability (`.agents/agents/accessibility-auditor/agent.md`).
- **@backend-architect**: API design, serverless functions, database schemas, server data flow (`.agents/agents/backend-architect/agent.md`).
- **@code-reviewer**: Post-implementation review for correctness, security, error handling, maintainability (`.agents/agents/code-reviewer/agent.md`).
- **@copy-editor**: Review UX text, documentation prose, tone, microcopy (`.agents/agents/copy-editor/agent.md`).
- **@debugger**: Focused root-cause investigation for bugs and unexplained failures (`.agents/agents/debugger/agent.md`).
- **@docs-writer**: Maintain codebase documentation, README files, API specs (`.agents/agents/docs-writer/agent.md`).
- **@performance-engineer**: Web Vitals, bundle size analysis, render optimization, memory leaks (`.agents/agents/performance-engineer/agent.md`).
- **@release-manager**: Build verification, dependency checks, deployment readiness (`.agents/agents/release-manager/agent.md`).
- **@test-engineer**: Unit, integration, e2e, and regression testing (`.agents/agents/test-engineer/agent.md`).
- **@ui-architect**: UI architecture, design system consistency, responsive layouts (`.agents/agents/ui-architect/agent.md`).
